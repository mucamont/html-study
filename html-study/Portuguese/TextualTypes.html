Textual Types

It's usually said that:

  • Narrativo
  • Argumentativo
  • Expositivo
  • Descritivo
It is good to know because allow you create good texts and how they work

Narrativo:

Definition: describe an actions in a while

How the text describes? : With apresentation → development → climax → outcome (and repeat...)

Argumentativo:

  • Definition: A text that expresses an opnion, with introduction, develpment and conclusion.

Expositivo:

  • Definition: A text that expresses an idea, should not contains any value judgments.
  • Objective: Provide information directly

Descritivo:

  • A text that just describe one thing

Injutivo:

  • A text that give instructions
